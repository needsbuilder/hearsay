Hearsay

Checks what coding agents say about the outside world against primary sources.

Is the agent's statement backed by a primary source?

Coding agents state facts in pull requests and chat answers: package versions, CVE fix versions, licences, documented parameters, deprecations, vendor API behaviour. Hearsay extracts those claims and checks each one. Registry and advisory facts are answered by PyPI, npm, deps.dev and OSV, without a model. Documentation claims are searched only on the official documentation site (through Tavily) and judged by a jury of models. A vote counts only with a quote that appears word for word in the documentation and, when the claim names a function, comes from that function's section. Without a primary source the verdict is unverifiable.
